# Edge API, команды и симулятор

## Purpose

Обеспечивает проверяемое поведение блока B03: edge api, команды и симулятор, в составе единой системы подсчета грузовых мест при загрузке вагонов.

## ADDED Requirements

### Requirement: WC-B03-R01 — Идемпотентная команда

Система SHALL проверять права и причину ручной правки и возвращать прежний результат повтора до проверки устаревшей control_version.

#### Scenario: WC-B03-R01-S01 — Проверка 1
- **WHEN** ответ на примененную +1 потерян и command_id повторен
- **THEN** один эффект и прежний applied

#### Scenario: WC-B03-R01-S02 — Проверка 2
- **WHEN** новая команда несет старую версию или чужой actor
- **THEN** 409 по версии; права назначает сервер

### Requirement: WC-B03-R02 — Срок и редакция

Система SHALL отклонять просроченные команды и сохранять предыдущие редакции при исправлении финального результата.

#### Scenario: WC-B03-R02-S01 — Проверка 1
- **WHEN** expires_at истек до первого применения
- **THEN** expired без дельты

#### Scenario: WC-B03-R02-S02 — Проверка 2
- **WHEN** оператор с отдельным правом исправил результат с причиной
- **THEN** revision+1, прежний снимок и аудит доступны

### Requirement: WC-B03-R03 — Локальный API

Система SHALL обслуживать авторизованного локального пользователя без центральных служб и подтверждать наблюдение после commit.

#### Scenario: WC-B03-R03-S01 — Проверка 1
- **WHEN** центр, PostgreSQL и MQTT остановлены
- **THEN** локальный вход и разрешенные команды работают

#### Scenario: WC-B03-R03-S02 — Проверка 2
- **WHEN** config_version Vision не совпадает
- **THEN** 409, счетный поток ждет согласования

### Requirement: WC-B03-R04 — Симулятор

Система SHALL использовать ObservationBatch через настоящий вход Edge и отдельные данные без рабочей ERP.

#### Scenario: WC-B03-R04-S01 — Проверка 1
- **WHEN** выполнены 10 входов и 2 возврата, затем ручная +1
- **THEN** счет 8, затем 9; повтор команды оставляет 9

#### Scenario: WC-B03-R04-S02 — Проверка 2
- **WHEN** симулятор направлен в live журнал
- **THEN** запуск отвергнут до изменения данных
