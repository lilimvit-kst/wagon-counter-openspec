# Среда, зависимости и CI

## Purpose

Обеспечивает проверяемое поведение блока B01: среда, зависимости и ci, в составе единой системы подсчета грузовых мест при загрузке вагонов.

## ADDED Requirements

### Requirement: WC-B01-R01 — Воспроизводимая поставка

Система SHALL строить сервисы из закрепленных зависимостей и поставленных моделей без установки пакетов при рабочем запуске.

#### Scenario: WC-B01-R01-S01 — Проверка 1
- **WHEN** повторены commit и locks
- **THEN** состав зависимостей воспроизведен

#### Scenario: WC-B01-R01-S02 — Проверка 2
- **WHEN** вес отсутствует
- **THEN** ошибка готовности вместо скачивания из Интернета

### Requirement: WC-B01-R02 — Устойчивая инфраструктура

Система SHALL сохранять данные при перезапуске и ограничивать доступ к служебным сервисам.

#### Scenario: WC-B01-R02-S01 — Проверка 1
- **WHEN** PostgreSQL и MQTT перезапущены
- **THEN** данные сохранены и прикладные операции выполняются

#### Scenario: WC-B01-R02-S02 — Проверка 2
- **WHEN** нет учетных данных MQTT
- **THEN** доступ отклонен

### Requirement: WC-B01-R03 — CPU совместимость

Система SHALL поддерживать обычный x86 CPU без Jetson/NVIDIA runtime и подтверждать CV набор испытанием.

#### Scenario: WC-B01-R03-S01 — Проверка 1
- **WHEN** контрольная модель экспортирована в OpenVINO
- **THEN** CPU inference проходит с сохраненной картой классов

#### Scenario: WC-B01-R03-S02 — Проверка 2
- **WHEN** pip check или экспорт не прошли
- **THEN** набор не принят; версии корректируются через ADR и новый lock
