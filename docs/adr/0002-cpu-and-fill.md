# ADR0002 — CPU и границы наблюдаемости

Статус: основание из ТЗ; производительность ожидает измерения.

Пилот — обычный x86 ПК и две камеры1080p/30. Начальный OpenVINO CPU анализирует верхнюю с целью10–15FPS, наклонную1–2FPS; скорость подтверждается временем прохода мешков и нагрузкой всего ПК. Обучение может идти на отдельной GPU.

План, видимая занятость и метрический объем имеют разные поля. Без принятой калибровки объем=null. OCR/двери допускают полный ручной процесс при неподходящем ракурсе.
