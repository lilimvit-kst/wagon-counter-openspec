# ADR0001 — Edge владеет счетом

Статус: основание из ТЗ; реализация B02–B04 ожидается.

Edge единолично подтверждает переходы и пишет журнал. Vision передает наблюдения; центр и UI — команды. Один writer SQLite сохраняет checkpoint/crossing/event/projection/outbox атомарно. Центр тем же чистым reducer строит проекцию и дает contiguous ACK после commit.

Это сохраняет учет при потере центра и повторной доставке. Исправления — события, финальный результат — редакции. Перенос владельца требует отдельного изменения с миграцией всех потребителей.
