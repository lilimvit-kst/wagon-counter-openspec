# ADR0003 — Различать план и реализацию

Статус: принято для этого комплекта 2026-09-10.

Используется штатная spec-driven схема OpenSpec1.13.0. Продуктовые планы B00–B14 находятся в changes, принятые возможности — в specs. Наличие четырех planning artifacts не доказывает выполненные задачи.

Граф/статусы/структуру доказательств проверяет собственный scripts/check_project.py поверх OpenSpec. Он не измеряет точность и не доказывает подлинность протокола. Штатные Codex skills обновляет CLI, проектные правила хранятся в AGENTS/config и отдельной инструкции.
