# Входы площадки и границы приемки

| Данные | Блок | Допустимая работа до получения |
| --- | --- | --- |
| Модель CPU/RAM/диск | B01,B08,B14 | Проверка на явно названном стенде, без гарантии скорости целевого ПК |
| RTSP/битрейт/кодек двух камер | B06 | Тестовые потоки1080p/30; реальное подключение требует проверки |
| Размеченные реальные видео четырех типов | B07,B08 | Инструменты обучения и replay, без заявления о принятой модели |
| ROI A/B и максимальная скорость | B08 | Simulator/replay; live с пустым ROI запрещен |
| Видимость номера и двери | B09 | Полный ручной процесс, unknown двери, auto_finalize=false |
| Система отсчета15° и область кузова | B10 | unavailable_reason; видимая занятость после проверки ROI |
| Геометрия и эталон объема | Отдельный объемный change | volume_m3 и volume_fill_ratio=null |
| URL/SKU/план/идемпотентность ERP | B13 | FakeERP с теми же контрактами; фактическая интеграция ожидает входов |
| Часовой пояс, DNS/TLS, сети операторов | B05,B12,B14 | Тестовые настройки обозначены как примеры |

Нехватка полевых данных не мешает B00–B05. При блокере выполнять независимую часть поручения; статус verified требует приемки предусмотренного режима. Общая yolo26n.pt не является обученной моделью мешков. Для OCR при включении минимум200 эпизодов и отдельная проверка ложных привязок; для физического объема отдельная методика.
